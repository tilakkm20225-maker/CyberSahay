# 8-week development roadmap

1. Setup, data provenance and label audit.
2. Preprocessing, deduplication and leakage-safe splits.
3. SMS baseline, metrics and false-positive review.
4. URL feature engineering and baseline model.
5. Explainability, multilingual dataset evaluation and safety assistant.
6. Community reporting workflow with privacy controls.
7. Testing, security review, Docker and CI.
8. Deployment, monitoring and final documentation.

Do not claim production-grade detection until tested on representative, independent data.
